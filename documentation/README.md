# Pajama & Loungewear Brand Website - Documentation

## Overview
This is a premium, fully responsive website for a sustainable cotton sleepwear brand. The design follows a clean luxury aesthetic with soft pastel tones, elegant spacing, and smooth animations.

## Folder Structure
- `assets/css`: Contains `style.css`, `dark-mode.css`, and `rtl.css`.
- `assets/js`: Contains `main.js` for interactivity.
- `assets/images`: Storage for optimized lifestyle images.
- `pages`: Inner pages of the website.
- `documentation`: Project documentation.

## Features
- **Responsive Design**: Mobile-first approach with breakpoints for Tablet, Laptop, and Large screens.
- **Theme Support**: Integrated Light and Dark modes with smooth transitions.
- **RTL Support**: Full support for Right-to-Left layouts.
- **Animations**: Reveal-on-scroll animations and premium hover effects.
- **SEO Optimized**: Semantic HTML5 structure and meta tags.

## Setup
Simply open `index.html` in any modern web browser to view the website. For development, using a local server like Live Server is recommended.
